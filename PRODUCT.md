# Qalam Product

## Register

product

## Users

Primary: people who build authority on LinkedIn for a living or for leverage. Founders, consultants, operators, coaches, ghostwriters, and agencies running client rosters. Secondary: professionals who also need the same evidence aimed at a job application. The secondary audience is served, not led with.

## Product Purpose

Qalam is a LinkedIn publishing system with memory. Anyone can generate a polished post now, so polished stopped being the differentiator. Qalam drafts from writing the user has already approved and facts they actually supplied, so the output still reads as them. Positioning, voice, content, and publishing sit in one workflow, with ATS resume targeting attached to the same Career Vault rather than framed as the headline. Success means credible authority the user is willing to put their name on.

## Brand Personality

Premium, credible, focused. The interface should feel calm and professional, with clear state feedback and restrained visual emphasis.

## Anti-references

Do not resemble a generic AI writer, a chatbot wrapped in a landing page, a fake analytics product, or a toy interface. Avoid emoji-led navigation, decorative clutter, weak contrast, inconsistent icons, and invented affordances.

## Design Principles

1. Make the current state unmistakable.
2. Keep professional workflows familiar and fast.
3. Use visual emphasis only for actions, selection, and status.
4. Preserve trust through factual copy and clear system behavior.
5. Prefer reusable patterns over one-off UI treatments.

## Accessibility & Inclusion

Maintain keyboard navigation, visible focus states, semantic labels, sufficient contrast, responsive layouts, and reduced-motion support. Never rely on color alone to communicate selection or status.
