## Founder post 04

No poster required. Use a real build screenshot.

I removed a claim from Qalam today.

It sounded strong.
It would probably convert.
But we could not prove it.

That matters because career products operate on trust.

If a platform cannot access recruiter behavior, it should not imply that it can.
If a score is a recommendation, it should not be presented as measured market data.
If an outcome depends on the user, it should not be framed as a guarantee.

We are building Qalam around a simple product rule:

Separate evidence, signals, inference, and recommendation.

Honest software may look quieter.
It builds stronger trust.

## Founder post 05

No poster required. Use the original Fizza portrait.

I think the blank page is blamed for the wrong problem.

Most people can write once they know what they want to say.

The real friction comes earlier:

What should I be known for?
Which experience is useful here?
Have I already made this point?
Does this sound like me?
How does it support where I want to go next?

That is not writer's block.
That is missing context.

So the product question for us is not only, "How do we generate a post?"

It is, "How do we carry the right professional context into every draft?"

Better context beats more output.
