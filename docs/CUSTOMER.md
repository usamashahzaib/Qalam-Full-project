# Customer

## Job Statement

When useful work is easy to forget or hard to explain, I want to capture it quickly and reuse it, so I can show credible progress without rebuilding my story every time.

## Job Dimensions

| Dimension | Desired progress | Current underdelivery |
|---|---|---|
| Functional | Save one useful work result in seconds and reuse it later | The dashboard used several abstract labels for one action |
| Emotional | Feel that today&apos;s effort counted and progress is possible | A score of zero and clinical language made the screen feel judgmental |
| Social | Explain real value clearly in posts, resumes, and interviews | The connection between a daily entry and future professional assets was hidden |

## Competing Alternatives

| Alternative | Why it is hired | Weakness |
|---|---|---|
| Notes app | Fast and familiar | Entries are not connected to career outputs |
| LinkedIn drafts | Close to publishing | Useful work that is not yet a post gets lost |
| Resume document | Familiar career record | Updated rarely and poor for daily capture |
| Memory | No setup | Results and details disappear quickly |
| Do nothing | No effort today | Creates repeated blank-page work later |
