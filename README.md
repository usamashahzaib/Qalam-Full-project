**Welcome to your Qalam project** 

**About**

View and Edit  your app on [www.byqalam.com](http://byqalam.com) 

This project contains everything you need to run your app locally.

**Edit the code in your local development environment**

Any change pushed to the repo will also be reflected in the Qalam Builder.

**Prerequisites:** 

1. Clone the repository using the project's Git URL 
2. Navigate to the project directory
3. Install dependencies: `npm install`
4. Create an `.env.local` file and set the right environment variables

Run the app: `npm run dev`

**Publish your changes**

Open [byQalam.com](http://byQalam.com) and click on Publish.
